# Sprite Localization Studio

Sprite Localization Studio is a localization tool for game UI sprite atlases. It reads textures and manifests generated by game asset tools, lets you manage sprites, text regions, and translations in a local workspace, and produces localized textures that preserve the original atlas layout.

The application is entirely frontend-based. Project files are stored directly in a local directory you choose.

## Web Version

Go to WEB version: https://samnyan.github.io/sprite-localization-studio/

## Input Format

Game-specific tools are responsible for unpacking and repacking game assets. To prepare input for Studio, follow the [Sprite Localization Input Format v1](documents/sprite-table-manifest-v1.md).

## Development

Node.js `^22.18.0 || >=24.12.0` and pnpm 11 are required.

```sh
pnpm install
pnpm dev
```

Access to local directories requires a Chromium browser that supports the File System Access API.
